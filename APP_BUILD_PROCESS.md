# App Build Process

This repository is the App Constitution template.

No application begins with code.

Every application must proceed in this order:

1. Define the app
2. Complete the domain model
3. Define invariants
4. Define domain rules
5. Define state machines
6. Define event model
7. Define observability
8. Define test plan
9. Generate implementation plan
10. Generate code
11. Run tests
12. Review
13. Deploy

## Rule

If a business rule, invariant, permission, risk policy, event, or lifecycle transition is unclear, stop and ask.

Do not invent domain logic.
